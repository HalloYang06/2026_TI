# ADR-007：RS00人工CSP微动作为正式闭环前的独立验收层

- 状态：Accepted
- 日期：2026-07-31

## 背景

只读Get_ID和参数读回能证明CAN链路，却不能证明模式设置、enable、`loc_ref`、实际角度跟随和stop可用。直接把M55 shadow目标接入电机又会把协议、实时控制和机构风险混在一次试验中。

## 决策

在M33增加独立的人工台架状态机，只开放RS00 CSP模式、保守速度/电流限制、极小位置步进、回位和stop。该路径由FinSH口令触发，所有发送仍由单一CAN worker执行；M55与自动算法继续`ACTUATOR_TX=0`。

RS00的`0x02`实测为命令响应而非可靠周期心跳。因此使能必须由新的`0x02`确认，进入微动后改用100 Hz定向读取`mechPos/mechVel`作为短时状态反馈。正式200 Hz控制仍需确认驱动器反馈能力、跟随延迟和总线调度后另行决策。

## 结果

2026-07-31在22 V、0.8 A软件限流、架空无载台架完成`1.684 -> 1.694 -> 1.687 rad -> stop`。CAN无发送失败、错误计数或FIFO丢失。人工执行器基础链路因此通过；滚球算法执行权没有因此开放。

## 后续门槛

1. 标定机构方向、零点、传动比和机械限位。
2. 做多组`+-10/20 mrad`阶跃，记录5%~95%上升时间、稳态误差、回差和电流。
3. 冻结正式200 Hz M33 CSP发布器、跟随误差门和失联停机语义。
4. 统一M33/M55共享地址并完成M55算法部署后，才允许shadow目标进入正式执行器安全门。
