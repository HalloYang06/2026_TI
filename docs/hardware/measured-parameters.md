# H题实物参数记录

Updated: 2026-07-31

## 钢球

| 参数 | 当前值 | 状态 | 来源 |
|---|---:|---|---|
| 质量 `m` | `4.11 g`（`0.00411 kg`） | 已由用户提供实测值；秤的分辨率待补 | 现场测量 |
| 直径 `D` | 约 `10 mm` | 题目/名义值，尚未用卡尺精测 | 题目条件 |
| 半径 `R` | 约 `5 mm` | 由名义直径推算 | 计算值 |

按实心钢球和名义半径计算：

```text
J = 2/5*m*R^2 = 4.11e-8 kg*m^2
F_g = m*g = 0.04031 N
rolling_factor = 1 / (1 + J/(m*R^2)) = 5/7
```

球位于摆杆中心外 `0.12 m` 和 `0.125 m` 时，水平附近由重力产生的准静态负载力矩分别约为：

```text
tau_0.12  = m*g*0.12  = 4.84 mN*m
tau_0.125 = m*g*0.125 = 5.04 mN*m
```

## 对控制模型的影响

- 在理想纯滚动方程中，质量与半径会约去，因此 `4.11 g` 不改变外层模型的 `5/7` 系数，也不要求仅因质量变化重新计算当前 LQR 增益。
- 质量必须进入摆杆执行器负载校核。角度内环辨识应分别进行空载和带球阶跃，当前仿真的 `25 ms` 时常最终采用带球结果。
- 当前端部碰撞用恢复系数和加速度脉冲近似。碰撞峰值、接触时间和脱轨风险需要用 `4.11 g` 实球的视频/传感记录重新标定。
- 打滑模型需要实测静摩擦和急加速边界。只有确认纯滚动假设成立，`5/7` 模型才可作为正式控制模型。

## RS00两连杆机构

| 参数 | 当前值 | 状态 |
|---|---:|---|
| 钢球可滚动水管有效长度 | `250 mm` | 用户给定；与CB不是同一个量 |
| 水管合页到连接点 `CB` | `300.1 mm` | 用户最终确认 |
| RS00主动曲柄 `OA` | `35.0 mm` | 用户给定 |
| 蓝色连接杆 `AB` | `55.5 mm` | 用户给定 |
| RS00轴心 `O` 高度 | `38 mm` | 用户给定 |
| 水管右侧合页轴心 `C` 高度 | `93 mm` | 用户给定 |
| 固定轴 `O-C` 水平距离 | `285 mm` | 用户给定 |
| 支撑台最低高度 | `50 mm` | 用户最终更正 |
| 水平时 `B-O` 水平偏置 | `-15.1 mm` | B在O左侧 |

C是右侧固定合页，水管水平时`C->B`向左；O位于C左侧285 mm、低55 mm。若水管外径约
50 mm且C轴与水管中心轴重合，管底约68 mm，满足支撑台不低于50 mm的约束。

2026-07-31 MATLAB机构分析结果：`+-6 deg`全部可达，RS00相对水平零位约需
`-57.00 deg`到`+70.68 deg`，最小`|dtheta/dq|=0.0467`，最差速度/力矩换算约
`21.43`。当前雅可比保护下连续区约`-6.47 deg`到`+6.79 deg`，因此软件硬指令暂定
`+-6 deg`、恢复角`+-5.5 deg`、水管斜率`0.35 rad/s`。水平RS00编码器原始读数和机械
干涉边界仍要无球标定，不能直接使用理论零偏。

## 钢球—水管接触

当前Simulink起始包络：

```text
mu_static = 0.050
mu_kinetic = 0.030
rolling_resistance = 0.002
```

这些是低摩擦暂定值，不是已完成的材料实测。应在2、3、4、5度斜管条件各重复至少10次，
并用带标记钢球的视频区分纯滚动与滑动。

## 下一步测量

1. 用卡尺沿至少三个方向测钢球直径并记录最小值、最大值和仪器分辨率。
2. 记录电子秤型号、分辨率及重复称量结果，给出质量不确定度。
3. 比较空载/带球摆杆小角度阶跃，辨识时常、纯延迟、死区和电机电流变化。
4. 用高速视频或带标记钢球测量何时开始打滑，冻结允许的最大摆角速度和加速度。
5. 实测合页轴高、全部孔距、水平RS00编码器角度、装配分支和机械干涉边界。
