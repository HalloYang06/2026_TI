# H题实物参数记录

Updated: 2026-07-29

## 钢球

| 参数 | 当前值 | 状态 | 来源 |
|---|---:|---|---|
| 质量 `m` | `4.11 g`（`0.00411 kg`） | 已由用户提供实测值；秤的分辨率待补 | 现场测量 |
| 直径 `D` | 约 `10 mm` | 题目/名义值，尚未用卡尺精测 | 题目条件 |
| 半径 `R` | 约 `5 mm` | 由名义直径推算 | 计算值 |

按实心钢球和名义半径计算：

```text
J = 2/5*m*R^2 = 4.11e-8 kg*m^2
F_g = m*g = 0.04031 N
rolling_factor = 1 / (1 + J/(m*R^2)) = 5/7
```

球位于摆杆中心外 `0.12 m` 和 `0.125 m` 时，水平附近由重力产生的准静态负载力矩分别约为：

```text
tau_0.12  = m*g*0.12  = 4.84 mN*m
tau_0.125 = m*g*0.125 = 5.04 mN*m
```

## 对控制模型的影响

- 在理想纯滚动方程中，质量与半径会约去，因此 `4.11 g` 不改变外层模型的 `5/7` 系数，也不要求仅因质量变化重新计算当前 LQR 增益。
- 质量必须进入摆杆执行器负载校核。角度内环辨识应分别进行空载和带球阶跃，当前仿真的 `25 ms` 时常最终采用带球结果。
- 当前端部碰撞用恢复系数和加速度脉冲近似。碰撞峰值、接触时间和脱轨风险需要用 `4.11 g` 实球的视频/传感记录重新标定。
- 打滑模型需要实测静摩擦和急加速边界。只有确认纯滚动假设成立，`5/7` 模型才可作为正式控制模型。

## 下一步测量

1. 用卡尺沿至少三个方向测钢球直径并记录最小值、最大值和仪器分辨率。
2. 记录电子秤型号、分辨率及重复称量结果，给出质量不确定度。
3. 比较空载/带球摆杆小角度阶跃，辨识时常、纯延迟、死区和电机电流变化。
4. 用高速视频或带标记钢球测量何时开始打滑，冻结允许的最大摆角速度和加速度。
