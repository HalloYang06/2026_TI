# 固件对齐的钢球 Simulink 重建设计

## 目标

把 `experiments/h_ball_control_simulink` 从“机构与算法可行性模型”升级为“当前 Q4/Q5/Q6 烧录固件的离线镜像”。模型的唯一参数基线是 M33 源码，不把旧的 ±6° motion-mode 假设用于评价当前实车。

成功标准：给同一段记录的参考、视觉、IMU、实际电机角和底盘轨迹后，模型使用和固件相同的控制周期、控制律、限幅和 CSP 执行器约束；输出可比较的管角、球位置、误差、饱和时间和端部恢复事件。它用于筛选候选参数，不能替代实车验收。

## 方案选择

1. 只改旧模型的几个常数：快，但 KF、CSP 和限幅逻辑仍不一致，不能解释实车差异。

2. **推荐：增加固件镜像 profile 和离散控制器，保留现有非线性钢球/四连杆 plant。**模型能继续做物理包线测试，又能直接回放现在的 Q4/Q5/Q6 控制律。

3. 只做 CSV 曲线分析：能量化实车，却无法预测改参数后的效果。

采用方案 2，并保留现有旧模型作为“理想机构包线”对照，文件名明确标为 `legacy`，不覆盖历史结果。

## 固件镜像参数

新建 `firmware_q456_profile.m`，其值由以下烧录源码镜像而来：

| 项目 | 模型值 |
| --- | ---: |
| 外环周期 | 2 ms / 500 Hz |
| Q4 `Kp/Kv/Ki` | `2.20 / 1.60 / 0.05` |
| Q5 `Kp/Kv/Ki` | `2.20 / 1.60 / 0.05` |
| Q6 `Kp/Kv/Ki` | `2.50 / 1.15 / 0.18` |
| 纵向前馈增益 | 0.55 |
| 横向耦合 | Q4/Q5 0.25；Q6 0.50 |
| 正常/恢复角度 | ±2° / ±2.5° |
| 正常/恢复管角斜率 | 0.50 / 0.75 rad/s |
| CSP 内环 | 位置 `Kp=120`、速度上限 5 rad/s、电流上限 2 A |
| Q4/Q5 软启动 | 1.20 s |
| Q6 软启动 | 目标位置相关，1.20–1.80 s |

固件与模型均采用同一四连杆尺寸和相对坐标。几何零位 `3.051858... rad` 和实物编码器调平值不是同一坐标；模型只在以实测编码器调平值初始化后比较绝对电机角。当前 `1.7205 rad` 与 Q3/Q4–Q6 运行中使用的 `1.7500 rad` 必须作为独立记录项，不擅自合并。

## 模型架构

```text
任务 profile + TI 底盘 S 曲线
      -> 500 Hz 固件镜像控制器
      -> CSP 执行器（限速/限流/延迟）
      -> 四连杆 -> 非线性钢球 plant
      -> 视觉延迟/IMU条件化 -> 控制器
```

控制器镜像以下实际逻辑：三状态 `x/v/扰动`预测、32 步历史回放的延迟视觉更新、IMU 静止 bias 锁定与 80 ms 条件化、纵向/横向/向心加速度前馈、积分抗饱和、正常/恢复限幅、管角速率限制和四连杆逆解。Q3 保持现有独立 PID，不混入该 Q4–Q6 模型。

执行器不再使用旧模型的 motion-mode `Kp=40/Kd=2/9 rad/s/5 N·m`。新 CSP 子模型按当前位置参考、`Kp=120`、5 rad/s、2 A 和可辨识的命令/反馈延迟运行；未经实测的摩擦、惯量和回差继续标识为待辨识参数，而非写成“已验证”。

## 实车回灌与缺失数据

导入器改为显式 `mission` 选择：`q3`、`q4`、`q5`、`q6`、`all`；Q6 分析器不得再通过 Q3 专用过滤。导入后输出统一 timeseries 与四项指标：最大误差、稳态偏差、进入 ±1 cm 时间、饱和时间。

现有 HBLG V1 只稳定记录纵向加速度和俯仰。它足以回放直线段，不足以严格重放 Q6 出弯的横向耦合和向心项。模型会在 X/Y/yaw 缺失时明确标记 `turn_replay_valid=false`，而不是把零值误当实测；完整 Q6 转弯对拍需要扩展日志字段后重新采集。

## 验证

1. 自动检查 profile 是否等于当前固件宏；任一关键值变化时，模型检查失败，不允许静默漂移。

2. 用无运动/零误差输入验证：管角、电机目标和积分都不漂移。

3. 用固定直线加速度回放验证：前馈方向与烧录 C 控制器一致。

4. 用一段 Q4/Q5 实车 HBLG 回放，先拟合相机延迟、CSP 阶跃响应和滚阻；模型球位与实测球位的 RMS、峰值误差写入结果。

5. Q6 只在 X/Y/yaw 完整记录后做出弯参数预测；此前只报告直线段结论。

## 边界

- 这轮不修改当前电机控制、Q3 PID、Q4/Q5/Q6 烧录参数或状态机。
- 这轮不宣称任何仿真结果等价于实车通过 ±1 cm。
- 需要新的 Q6 全量转弯日志时，协议扩展作为独立、兼容 V1 的后续改动。
