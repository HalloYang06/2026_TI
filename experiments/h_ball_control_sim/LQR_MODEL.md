# EdgeTalk 非线性前馈 + 增广 LQG 数学模型

> 本文记录旧Python回归模型，不是当前RS00两连杆部署规范。当前100 Hz视觉、
> OOSM KF + LQI、机构和安全门以
> `docs/architecture/h-ball-control-implementation-plan.md`及
> `experiments/h_ball_control_simulink/`为准。

## 1. 建模目标

控制算法最终运行在 EdgeTalk。当前正式目标为树莓派100 Hz带时间戳和置信度的钢球位置；本文旧回归仍保留60 Hz压力档。MSPM0G3507以200 Hz镜像车体加速度、俯仰角和偏航角速度，但源采样率必须单独验证。EdgeTalk M55以200 Hz运行LQG，M33以1 kHz执行目标角安全监督，并以200 Hz向RS00发送受限位置参考。RS00以250~500 Hz返回无刷电机/摆杆角度，位置环和FOC由驱动器内部闭合，内部频率在取得厂家资料或实测前不写死。

LQR 不直接控制三相 PWM，而是输出摆杆目标角度。首版采用RS00 CSP位置模式，M33写入受限`loc_ref`并配置保守的速度/电流上限；无刷位置环和FOC作为已经闭合的快速执行器。MIT位置-速度阻抗模式仅为CSP带宽不达标时的备选，纯速度和纯力矩/电流模式不作为首版。

## 2. 非线性被控对象

定义钢球沿摆杆位置为 `x`，速度为 `v`，摆杆相对车体角度为 `alpha`，车身俯仰角为 `theta`，纵向加速度为 `a_x`，横向加速度为 `a_y`，偏航角速度为 `r`。摆杆中心相对车辆旋转中心的纵向距离为 `l_c`，安装偏角为 `delta`。

实心钢球纯滚动模型：

```text
J = 2/5*m*R^2
m_eff = m + J/R^2 = 7/5*m
rolling_factor = m/m_eff = 5/7
```

因此模型已经包含钢球的平动惯性和绕自身球心的转动惯量。理想纯滚动时，质量 `m` 和半径 `R` 会从加速度方程中约去；钢材密度不会改变 `5/7`，但会影响摆杆所受反力、接触变形、滚动阻力、碰撞冲量和打滑边界。钢球质量已实测为 `4.11 g`；直径仍暂按题目的约 `10 mm`，由此得到暂定转动惯量 `J=4.11e-8 kg*m^2`。直径精测与不确定度见 `docs/hardware/measured-parameters.md`。

```text
x_ddot = 5/7 * [
    g*sin(alpha + theta)
    - a_x*cos(alpha + theta)
    + r^2*(l_c + x)
    - a_y*sin(delta)
] - c*v + d
```

`d` 表示摩擦、水平零点和未建模扰动。仿真被控对象保留正弦、余弦、粘性阻尼和平滑库仑摩擦。

## 3. 可测扰动前馈

令稳态钢球加速度为零，可以求出非线性摆杆前馈角 `alpha_ff`：

```text
g*sin(alpha_ff + theta)
- a_x*cos(alpha_ff + theta)
+ r^2*(l_c + x)
- a_y*sin(delta) = 0
```

小角度近似为：

```text
alpha_ff ~= [a_x - r^2*(l_c + x) + a_y*sin(delta)] / g - theta
```

直线加减速、车身俯仰和转弯角速度先由前馈抵消，LQR 主要负责消除剩余位置和速度误差。

## 4. 增广线性模型

快速摆杆执行器用一阶模型表示：

```text
alpha_dot = (u - alpha) / tau
```

其中 `u` 是 EdgeTalk 输出的摆杆目标角，`tau` 暂取 25 ms。

在水平位置附近线性化，并将前馈工作点移到原点：

```text
X = [e, v, alpha_tilde]^T
e = x - x_ref
alpha_tilde = alpha - alpha_ff
u_tilde = u - alpha_ff
```

连续状态空间模型：

```text
X_dot = A*X + B*u_tilde

A = [[0, 1,       0],
     [0, 0, 5*g/7  ],
     [0, 0,   -1/tau]]

B = [[0],
     [0],
     [1/tau]]
```

控制周期 `T_s = 5 ms`，用零阶保持离散化：

```text
X[k+1] = A_d*X[k] + B_d*u_tilde[k]
```

## 5. LQR 代价函数与暂定参数

离散无限时域代价函数：

```text
J = sum(X[k]^T*Q*X[k] + u_tilde[k]^T*R*u_tilde[k])
```

第一轮参数：

```text
Q = diag(1200, 25, 2)
R = 5.0
T_s = 0.005 s
tau = 0.025 s
```

求解离散 Riccati 方程得到：

```text
K = [14.56338, 3.31547, 0.58093]
```

控制律：

```text
u = alpha_ff - K*[e, v_hat, alpha-alpha_ff]^T
```

仿真计算的离散闭环极点：

```text
[0.79744, 0.95252+0.00525j, 0.95252-0.00525j]
```

全部位于单位圆内，线性离散系统稳定。最终输出再经过 `+-4 deg` 角度限幅和 `80 deg/s` 目标角速度限制，避免视觉与IMU噪声让无刷目标角高频跳变。

## 6. 延迟、离群点和球速状态观测器

摄像头只能测位置，且约有 33 ms 延迟，因此 EdgeTalk 内部观测状态：

```text
X_hat = [x_hat, v_hat, d_hat]^T
```

EdgeTalk 以 200 Hz 用非线性模型预测位置和速度；每当 60 Hz 摄像头数据到达时，根据图像采集时间戳将历史位置预测到当前时刻，再执行 Kalman 测量更新。`d_hat` 用于估计摩擦、IMU零偏和机构水平误差，并转化为角度补偿。

这里的60 Hz是既有压力战役保留的保守仿真档，不代表正式链路目标；当前树莓派识别目标为100 Hz，USB按240 Hz验收。旧Python结果保持原参数作回归，新的100 Hz对照和两连杆结果位于`experiments/h_ball_control_simulink/`。

视觉位置还进入 5 帧带时间戳的二次最小二乘窗口，拟合当前球速。该速度只作为 Kalman 速度观测，不直接差分后送进 LQR，避免单帧像素噪声被 `1/dt` 放大。

视觉更新使用 4 倍标准差创新门限。孤立反光点在进入位置和球速估计前被拒绝；连续拒帧时逐步膨胀位置协方差，使持续一致的新位置可在约 6 帧内重新被接纳，避免硬门限导致永久失锁。滤波器按 `1.2 mm` 标称视觉标准差整定，刻意比基准仿真的 `0.7 mm` 噪声保守。

## 7. 当前仿真工况

- 仿真总长：25 s。
- 底层积分：1 kHz。
- LQR与状态预测：200 Hz。
- 摄像头：60 Hz，延迟 33 ms，位置噪声标准差 0.7 mm。
- IMU链路：5 ms延迟，纵向/横向加速度噪声标准差 0.01 m/s^2。
- 弯道偏航角速度：0.62 rad/s。
- 最大纵向加速度：0.25 m/s^2。
- 被控对象与控制模型故意保留参数失配和未建模摩擦。
- 压力工况将视觉延迟增至50 ms、噪声增至1.2 mm、执行器时间常数增至40 ms，并注入两次80 ms视觉丢帧。

## 8. 基准、消融和题目功能项结果

| 工况 | 峰值误差 | RMS误差 | 超出1cm时间 | 最大实际摆角 |
|---|---:|---:|---:|---:|
| 基准 | 4.00 mm | 0.48 mm | 0 s | 2.26 deg |
| 固定压力 | 4.00 mm | 0.65 mm | 0 s | 2.52 deg |

峰值由初始 4 mm 位置偏差产生；车辆加减速和弯道过程中误差均未超过题目 1 cm 限制。该结果证明模型和参数具有数值可行性，但不能替代实物标定。

在相同运动工况、初始位置为 0 的消融测试中，去掉加速度/俯仰/转弯前馈后，峰值误差为 `3.43 mm`、RMS 为 `0.883 mm`；保留前馈后分别降为 `1.51 mm` 和 `0.371 mm`。因此最终方案不是纯 LQR，而是“可测扰动非线性前馈 + LQG 剩余误差反馈”。

题目第 3 项的静止参考测试采用 `0 s -> +5 cm`、`2 s -> -5 cm`：进入并持续保持在 `+-1 cm` 误差带的时刻分别为 `0.492 s` 和总时刻 `3.070 s`，均早于 5 s 截止。运动中保持任意 `+5 cm` 指定位置的峰值误差为 `1.60 mm`。

## 9. 分级压力战役

最终运行 6 个压力等级、每级 12 个随机种子、每组 25 s，共 72 组。控制器始终使用标称 `25 ms` 执行器模型，不会随仿真中的实际电机退化重新整定。

| 等级 | 通过率 | P95峰值 | 最坏峰值 | 结论 |
|---:|---:|---:|---:|---|
| 0 | 12/12 | 3.77 mm | 3.87 mm | 基准通过 |
| 1 | 12/12 | 3.81 mm | 3.86 mm | 轻度干扰通过 |
| 2 | 12/12 | 5.57 mm | 6.48 mm | 当前可信设计包络 |
| 3 | 10/12 | 19.62 mm | 30.85 mm | 首次出现失效 |
| 4 | 2/12 | 19.29 mm | 19.92 mm | 大部分失效 |
| 5 | 0/12 | 73.43 mm | 120.00 mm | 全部失效 |

2 级压力包含约 `45~53 ms` 视觉延迟、`1.2~1.5 mm` 单帧噪声、最长约 `120 ms` 连续丢帧、`2.4%` MSPM0 状态包丢失、`49 ms` 实际执行器时常、`8 ms` 指令延迟、`84%` 执行器增益、`0.08 deg` 死区以及多次轨道冲击。12 个种子全部满足 1 cm，故可把 2 级作为第一版实物验收目标。

首个失效位于 3 级、trial 2 和 trial 11。最坏 trial 11 在 `18.907 s` 超过 1 cm；其 `18.30~18.69 s` 附近连续出现两个视觉空窗，并叠加 `18.62 s` 的轨道冲击，实际执行器时常为 `61 ms`、指令延迟 `12 ms`、增益仅 `76%`。这说明下一轮机械和软件优化优先级应是减少相机长空窗、减小摆杆机构时常/回差、降低轨道接缝冲击，而不是继续增大 LQR 增益。

相关性排名中的视觉噪声、静摩擦、最长视觉空窗、IMU 延迟和执行器退化都随压力等级共同增加，因此只能用于筛查，不能当作独立因果贡献率。

## 10. 三块板和多速率落地

| 环节 | 建议频率 | 执行位置 | 说明 |
|---|---:|---|---|
| 红外循迹采样 | 1 kHz | MSPM0 | 只允许红外光电循迹；DMA/定时器固定周期 |
| 底盘速度/差速环 | 500 Hz | MSPM0 | 与滚球算法解耦，输出车速与转弯状态 |
| IMU内部采样/读取 | 1 kHz | MSPM0 | UART DMA；低通后每 5 个样本发送一次 |
| IMU/底盘状态包 | 200 Hz | MSPM0 -> EdgeTalk | 带单调时间戳、序号、CRC；丢包保持并超时降级 |
| 摄像头采集与识别 | 100 Hz | 树莓派 | 发送球位置、置信度、曝光时间戳，不传整帧给控制器 |
| 球状态预测与LQG | 200 Hz | EdgeTalk | 固定 5 ms 周期；视觉到达时异步更新 |
| 目标角安全监督 | 1 kHz | EdgeTalk M33 | freshness、有限值、`+-4 deg`限幅和`80 deg/s`限速 |
| CSP位置参考 | 200 Hz，当前禁用 | EdgeTalk M33 -> RS00 | `loc_ref`加保守`limit_spd/limit_cur`，自动测试不发送 |
| RS00角度/速度反馈 | 250~500 Hz，待实测 | RS00 -> EdgeTalk M33 | 编码器角度、速度、温度、故障和跟随误差诊断 |
| 位置环与FOC | 驱动器内部频率，待厂家资料/实测 | RS00内部 | 不在EdgeTalk重复实现三相电流环 |

IMU 可以使用 UART。若一个状态包按 32 byte 估算，8N1 下 200 Hz 需要约 `64 kbit/s`；`115200 bit/s` 理论可用但余量小，推荐 `460800` 或 `921600 bit/s`、DMA 接收、二进制定长帧、硬件时间戳/序号/CRC。不要用字符串打印协议承载控制数据。

四类信息并非塞进一个同频 PID：钢球位置与估计球速进入外层 LQG；加速度、俯仰和角速度进入状态预测及前馈；无刷角度反馈由M33用于CSP跟随误差和安全监督，快速位置/FOC闭环留在RS00内部。这样的分层能避免120 Hz摄像头拖慢执行器内部闭环。

## 11. 实物验收门槛

- 先用车轮架空、底盘动力断开或限流电源、硬件急停、操作员可直接断电的台架测摆杆角度阶跃；不得由自动化脚本解锁电机。
- 识别 `5%~95%` 摆角上升时间、纯延迟、最大角速度、死区和回差。若实际一阶时常大于 `49 ms`、指令延迟大于 `8 ms` 或有效增益低于 `84%`，不得直接宣称达到当前 2 级包络，应把实测值回填仿真。
- 用带时间戳录像统计球位置噪声标准差、P95 延迟、最长连续丢帧。首先保证 P95 延迟小于 `50 ms`、连续空窗小于 `120 ms`。
- 静态标定摆杆水平零点、球滚动阻尼、静摩擦和编码器角度到真实摆角映射；转弯实测后再标定 `l_c`、安装偏角和槽壁附加摩擦。
- 先完成静止 `0 -> +5 cm -> -5 cm`，再车轮架空重放记录的 IMU/视觉数据，最后才在低速地面测试。

## 12. 模型限制

- 无刷转子角度到摆杆角度的真实映射。
- EdgeTalk无刷位置环的实际时间常数和最大角速度。
- 摄像头采集到控制量生效的95%延迟。
- IMU安装位置、坐标方向、UART内部滤波延迟。
- 摆杆摩擦、钢球滚动阻尼和曲柄回差。
- 当前假定钢球纯滚动且不打滑，没有把球的自转角速度作为独立状态；实物必须测量急加减速、冲击和大摆角下的打滑阈值。
- 当前执行器采用一阶模型，没有显式耦合约4 g钢球在不同位置对摆杆产生的反作用力矩；需用空载/带球摆角阶跃对比辨识该影响。
- 端部碰撞目前用恢复系数和外加速度脉冲近似，没有求解质量、接触刚度和阻尼决定的接触过程。
- 当前仍是一维模型；槽截面内横向摆动、球自旋、PPR 管弹性、连杆间隙和车架扭转未完整建模。
- 轨道冲击用短时加速度脉冲近似，压力等级不是现场故障概率。
- 视觉延迟补偿采用当前速度/加速度外推，不是完整固定滞后平滑器。
- 仿真通过不能替代实车视频、编码器和 IMU 同步日志。
