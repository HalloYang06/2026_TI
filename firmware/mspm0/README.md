# 天猛星 MSPM0G3507 底盘固件

当前实机循迹工程位于
[wit-oled-hardware-spi](wit-oled-hardware-spi/README.md)。

## 当前状态

用户已确定继续使用上一年参赛的天猛星/MSPM0G3507作为底盘控制器。具体引脚、红外阵列、IMU型号、底盘驱动器和编码器接口待提供，因此当前只冻结职责与频率，不写板级初始化代码。

## 计划职责

| 任务 | 频率 | 要求 |
|---|---:|---|
| 红外光电采样 | 1 kHz | 定时器触发；比赛正式循迹只使用允许的红外光电信息 |
| IMU UART DMA接收 | 1 kHz内部采样 | 二进制帧、校验、传感器时间戳；不在控制链传ASCII日志 |
| 底盘速度/差速环 | 500 Hz | 保持原底盘控制经验，与滚球算法解耦 |
| 左右轮编码器/里程计 | 500 Hz | 输出实际轮速和曲率，不只输出目标值 |
| 状态发布 | 200 Hz | 加速度、俯仰、偏航角速度、轮速、故障、序号、时间戳、CRC |

滚球 LQG不放在 MSPM0。MSPM0只保证底盘实时控制和可靠状态采集；EdgeTalk根据这些状态计算摆杆目标。

## IMU串口建议

- 推荐 `460800` 或 `921600 bit/s`、8N1、UART RX DMA环形缓冲。
- 传感器若只支持 `115200`，应先测真实输出帧长、突发间隔和最大解析延迟；理论带宽够不等于控制余量够。
- 加速度和角速度先做坐标系转换、量程检查和抗混叠低通，再从1 kHz聚合为200 Hz状态包。
- 状态包携带采样时刻而不是发送完成时刻；检测丢帧、乱序、CRC错误和传感器重启。
